# Project Rules & Guidelines for Musify

## UI Design System & Aesthetic Rules
- **Minimal & Clean**: All UI in this application must be strictly minimal, clean, and elegant.
- **Flat Surfaces & No Glow**: Never use glowing effects, neon borders/shadows, or artificial glow around cards, icons, or buttons.
- **No Gradients on Buttons**: Buttons must use flat, solid colors or clean subtle borders. Do NOT use multi-color gradients or glowing gradients on action buttons.
- **Consistent Visual Language**: Prioritize high readability, crisp typography, subtle neutral surfaces, and clean spacing over ornate decorative elements.
